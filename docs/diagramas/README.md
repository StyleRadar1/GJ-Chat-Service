## Cómo editar un diagrama

1. Abre el `.drawio` en draw.io (web o escritorio).
2. Carga la plantilla `StyleRadar-Componentes.xml` en *Archivo → Abrir biblioteca desde* para usar sus formas.
3. Edita, y exporta con *Archivo → Exportar como → PNG* (escala 200 %, fondo blanco) con el mismo nombre del archivo.
4. Sube el `.drawio` y el `.png` en el mismo commit.
